# GIDICOB Student Service Queue Website

## Files
- `index.html` — interactive service desk dashboard
- `style.css` — responsive styling
- `script.js` — queue operations and browser storage
- `student_service_queue.cpp` — console version in C++
- `README.md` — instructions

## Open the website
Extract the ZIP and open `index.html` in a browser.

## Publish using GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md`.
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main` and `/(root)`, then save.
5. GitHub Pages will show the published URL when deployment finishes.

This is a working front-end demonstration. Its queue data is stored in the current browser only; a shared queue across devices requires a backend/database.
